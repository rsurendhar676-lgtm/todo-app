# Todo App

A beginner-friendly todo list built with HTML, CSS, and JavaScript. Todos are saved in the browser with LocalStorage.

## How to run

Open `index.html` in a web browser (double-click the file). No install or server is required.

## What you can do

- Add a todo and press Enter (or click Add)
- Check a todo to mark it complete
- Double-click a title to edit it (Enter to save, Escape to cancel)
- Delete a todo
- Filter All, Active, or Completed
- Clear completed todos

## Project files

- `index.html` — page structure and script tags
- `css/styles.css` — styles
- `js/storage.js` — load and save todos
- `js/render.js` — draw the list
- `js/app.js` — app behavior
